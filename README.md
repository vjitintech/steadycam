# SteadyCam

Software-only video stabilization for phone cameras. Removes hand shake and
forward/back size wobble in real time, with no gimbal or stand.

- `index.html` — the app (open over HTTPS in Safari or Chrome, tap **Camera**)
- `steadycam.js` — drop-in SDK for other web camera apps
- `src/` — engine source, `test/` — automated tests (`node test/test.js`)
