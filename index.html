Enable it in any camera app

The same engine ships as a drop-in script. Point it at the app's camera <video>, and it returns a stabilized canvas and a MediaStream for recording, streaming or video calls.

<script src="steadycam.js"></script>
<script>
  const cam = new SteadyCam(videoEl, { mode: 'smooth', crop: 0.1 });
  cam.start();                                  // stabilized frames → cam.canvas
  document.body.append(cam.canvas);
  const rec = new MediaRecorder(cam.captureStream(30));
  cam.setMode('lock');                          // tripod-style framing hold
</script>
