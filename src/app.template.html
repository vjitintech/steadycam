    Plug it into any camera app

    Other web apps turn it on with one line. Every camera stream they open comes back stabilized, so their recording, streaming and video calls get it with no other changes.

    <script src="steadycam.js"></script>
<script>
  SteadyCam.install({ mode: 'smooth' });   // every getUserMedia video is now stabilized

  // or wrap a stream yourself and keep control:
  const { stream, cam } = await SteadyCam.stabilizeStream(cameraStream, { mode: 'target', output: 1080 });
  cam.lockAtScreen(x, y);   cam.setZoom(2);   cam.unlock();
  const rec = new SteadyCam.Recorder(stream, cam);  rec.start();  const clip = await rec.stop();
</script>

    Live camera works when this page is opened directly in Safari or Chrome over HTTPS. Inside a preview, use Demo or Video file.
